# TIME MOVIES

An offline-first Flutter movie and series library. The app has no catalog, API, analytics service, or remote media dependency: only videos imported on the device appear.

## Local media flow

1. Sign in or create a local session using the login screen.
2. Choose a profile, then tap `+` or `Add movie or series`.
3. Pick a video from the device file picker. The app immediately copies it into the app documents directory under `videos/` with a unique name.
4. Enter a title and category. Select a poster, or let the app generate a JPEG thumbnail from the copied video.
5. SQLite stores the title, category, copied video path, thumbnail path, and import timestamp.
6. Home groups each imported title by its selected category. Playback uses `VideoPlayerController.file` with the copied path, so it does not need Wi-Fi or mobile data and remains available after the source file is deleted.

## Run locally

Install Flutter 3.24 or newer, then run:

```bash
flutter pub get
flutter run
```

The repository currently contains the platform-independent Flutter source. The Android host project is generated by the CI workflow with `flutter create --platforms=android .`, which keeps the checked-in app code small while producing a standard release APK.

## Release APK

Every push, on any branch, runs `.github/workflows/release-apk.yml`. Open the completed GitHub Actions run and download the `time-movies-release` artifact.
